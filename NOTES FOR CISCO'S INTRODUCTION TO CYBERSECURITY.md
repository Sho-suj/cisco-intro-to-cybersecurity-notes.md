It is an ongoing effort to protect an individual/organization/government from digital attacks by protecting the network system and data from malicious individual.

1. From an individual level: it is important for us to protect our sensitive information (eg: Bank details, date of birth, etc.)
2. From an organization level: it is important for us to protect sensitive information of our customer and stake holders

**The** **Cube**:

The McCumber Cube is a model framework created by John McCumber in1991 to help all the factors that can impact the security of data.

This model has 3 main dimensions:

1. The foundation principles for protecting information
2. Security measures used to protect data
3. The protection of information in each of its possible states.

**The Foundational Principles for protecting information**

- Confidentiality: It means that sensitive information are kept confidential from public/malicious views. Maintaining confidentiality can be done using encryption, multi-factor authentication and identity-proofing.
- Integrity: It means maintaining the data in its true state without allowing unauthorized users from changing the data. Methods of maintaining it are hash function or checksum.
- Availability: Ensuring that authorized users are able to access the system and data is availability.

**Protection of information in each State**

1. Processing: Data used to perform a task
2. Storage: Saving data
3. Transmission: Travelling of data through different devices

**Security Measures Used to protect data**

1. Awareness, training and education: Measures/learning programs put in place for the members of the organization to create awareness of good security practices to maintain security of the system and data
2. Technology: Hardware and software-based solutions designed to maintain integrity of the security in the system. For example: a firewall that checks the system for any unwanted/ suspicious activities.
3. Policy and procedure: Steps created by an organization for individuals to follow to maintain good security or to reduce the damage caused during data breaches or cyberattacks.

**Phishing emails**

Phishing emails are one of the most common ways that data breaches occur. It is very important to distinguish between a phishing email and an actual one. Some common signs are:

- the sender's email domain is spelled incorrectly
- the link URL is not pointing to the website

**Types Of Malware**

Malware is any type of code used to steal information, by-pass access control, and cause harm to comprise a system.

1. Spyware: Malware developed to spy on you. They allow the attacker to view everything on your system, including keyboard inputs. Commonly found alongside Trojan horses.
2. Adware: Malware that makes random advertisement pop up on your system.
3. Backdoor: Allows attackers to enter your system and start privliege escalation by bypassing normal authentication.
4. Ransomware: Malware that encrypts sensitive data, allowing attackers to ask for a ransom in order to give a decryption key.
5. Scareware: Shows pop-ups in order to scare an individual to download specific software.
6. Rootkit: Malware that allows the development of backdoor for the attacker to control your system.
7. Virus: Self-replicating code that corrupts the system. A virus needs to attach itself to a host file/program and needs a human to actually run it. Usually transferred from USB, CD or sharing files from the internet.
8. Trojan Horse: Hides and corrupts the system.
9. Worms: Self-replicating code that doesn't need a source file in order to multiply. Additionally, it doesn't require an individual to activate it.

**Signs of Malware**

1. Increase in the use of CPU
2. Device running slowly or freezing frequently
3. Decrease in the web browsing speed
4. Modification or deletion of files and folders
5. Unknown processes running in the background
6. Unknown applications, desktop icons or files appearing on your device
7. Emails being sent without your consent or knowledge
8. Unexplainable problems with network connection
9. Programs turning off or randomly reconfiguring themselves

**Social Engineering**

In simple terms, hacking without code. It is a method used by hackers to gain vital information about the target individual or system in order to gain more sensitive or vital data. Instead of attacking the system directly, the goal is to attack the individual. Some common types of social engineering are:

1. Pre-texting: Calling someone and lying to them in order to gain access to privileged data.
2. Tailgating: Following an authorized personal into a restricted area.
3. Something-for-something: This is when an attacker requests sensitive information for something in return like an expensive gift.

**Denial-of-Service (DoS)**

It is a simple network attack, that causes an individual, device or application to lose access to a network service.

It can be caused because of:

1. Overwhelming network traffic: Done when the host/application receives enormous amount of data, more than it can handle, resulting in the slow down, crash or freezing of the website or application.
2. Packet maliciously formatted: _A packet is a collection of data that flows between a sender and receiver application or computer through the internet_. When an application/system receives a maliciously formatted packet it won't be able to process it resulting in the crash it.

DoS attacks are considered a major threat as they can cause a huge waste of time and money.

**Distributed DoS**

It is similar to DoS but originates from multiple coordinated sources.

- An attacker creates a network of multiple botnet called zombies which are controlled by handler systems.
- The zombie bot then scans and infects more system and creates more zombies.
- When ready, the attacker instructs the handler system to commence a DDoS attack.

**Botnets**

Botnets are usually created when a computer goes on a malicious website, or by opening an infected email or application. Botnets are group of bots, connected through the internet that can be control by malicious individuals or group. It can have tens of thousands to hundreds of thousands of bots that are typically controlled through command or control server.

These bots can be activated to distribute malware, launch DDoS attacks, distribute spam email, or execute brute-force password attacks. Cybercriminals will often rent out botnets to third parties for nefarious purposes.

**Password Attacks**

Username and password is one of the most common ways of authenticating to a website. Therefore having access to your password is one of the easiest ways to gain access to sensitive information.

- Password Spraying: Criminals attempts to gain access by 'spraying' commonly used password such as 'password123', with a variety of different usernames before trying with another very common password. Allows attackers to remain undetected as they avoid getting frequent account lockouts.
- Dictionary attack: An attacker tries very word in the dictionary in an attempt to break into password secured account.
- Brute-force attack: Most common means of attack, where an attacker tries to guess password by putting all sort of combinations of letters, number and special characters.
- Rainbow attack: Passwords in your computer are stored in hash, in this attack, the hacker compares the hash of a password with those stored in a rainbow table, which if matched, is identified as the password used to create the hash. A rainbow table is a pre-built answer key matching common passwords to their hashes — instead of cracking a hash directly, the attacker just looks it up
- Traffic Interception: Plain text or unencrypted passwords can be easily read by other people through intercepting communication.

**Security Vulnerability**

Any weakness in hardware or software of a system is called a _vulnerability_. A program thats used to take advantage of that vulnerability is called an _exploit_. A cybercriminal can use the exploit to _attack_ a system to gain access, extract data or a specific resource.

- Hardware Vulnerability: Most likely caused due to design flaw. Hardware vulnerabilities are specific to device models and are not generally exploited through random compromising attempts. While hardware exploits are more common in highly targeted attacks, traditional malware protection and good physical security are sufficient protection for the everyday user.
- Software Vulnerability: Usually caused because of errors in operating system and code.

**Categorizing Software Vulnerabilities**

Most software security vulnerabilities fall into several main categories:

1. Buffer overflow: Buffer are like storage containers used by application to store data temporarily. If data is stored more than it can handle it pores into other memory "boxes" hence corrupting them. Sometimes it can be accidental and crashes the program but attackers can do it on purpose, controlling what spills and take control over the program.
2. Non-validated input: Program requires data input, non-valid input can cause a program to behave in unintended ways. For example, a program that process images, can be fed an invalid image dimensions, which could force the program to allocate buffers of incorrect and unexpected sizes.
3. Race conditions: This vulnerability affects events that are timed or ordered. A race condition occurs when the timed or ordered events don't occur or happen at improper time.
4. Weaknesses in security practices: System and sensitive data can be protected using techniques such as authorization, authentication and encryption. Developers should stick to using security techniques and libraries that have been created, tested, and verified. Aiming to create a new security library will cause new vulnerability to show up.
5. Access Control problems: Access control is the process of controlling who does and ranges from who has physical access to equipment and what resources they can access. Many security vulnerability are created due to improper access control. If an attacker has physical access to the target equipment, they can bypass nearly all access control and security practices. Therefore, to protect the machine physical access must be restricted, and encryption techniques must be used to protect data from being stolen or corrupted.

**Cryptocurrency**

Cryptocurrency is digital currency that can be used to buy goods and services, using strong encryption techniques for secure online transaction.

Cryptocurrency owner keep their money in encrypted, virtual "wallets". When a transaction takes place, the details are recorded in a decentralized, electronic ledger or blockchain system. This means it is carried out with a degree of anonymity and is self-managed, with no interference from third parties such as central banks or government entities.

Approximately every ten minutes, special computers collect data about the latest cryptocurrency transactions, turning them into mathematical puzzles to maintain confidentiality.

These transactions are then verified through a technical and highly complex process known as ‘mining.’ This step typically involves an army of ‘miners’ working on high-end PCs to solve mathematical puzzles and authenticate transactions.

Once verified, the ledger is updated and electronically copied and disseminated worldwide to anyone belonging to the blockchain network, effectively completing a transaction.

**Wireless Network Security at Home**

Wireless networks are identified by an SSID (Service Set identifiers), which are the network names used to connect. While the SSID can be hidden from public view it is not an actual security measure as attackers with the right tools can still find the network.

A bigger vulnerability is default credentials. Routers come with a default SSID and password, publicly known or that can be looked up online using router model numbers, so these should be changed into something unique. Additionally for further protection, wireless communication encryption should be enabled by wireless security and WPA2 encryption should also be enabled. Note that even with WPA2 encryption, a wireless network can still be vulnerable.

This vulnerability can be exploited using Key Reinstallation Attacks (KRACKs) by attackers. What attackers do is they interrupt the encryption of wireless router with network devices, allowing them to have access to the whole network. This flaw affects all modern, protected WiFi-networks.

To mitigate this situation, what you can do is:

- When security updates are available for devices such as laptop, mobiles, and routers, update them as soon as possible.
- Use a trusted Virtual Private Network (VPN) when using a wireless network.
- Use a wired connection on devices with a Network Interface Card (NIC)

**Security Appliance**

Security appliance are the standalone devices like routers or software tools, that run on the network device. It falls under six categories:

1. Routers  
    Routers are primarily used to connect various network segments they also provide minimal traffic filtering capabilities. This can allow you to know which network segment can communicate with which network segment.
2. Firewalls  
    Firewalls have more control over the network traffic, allowing it to view and identify network traffic with malicious behavior and blocks it. Firewalls can have advanced security policies to filter traffic passing through them.
3. Intrusion Prevention System  
    IPS systems use a set of traffic signature that match and block malicious network traffic and attacks
4. Virtual Private Network  
    VPN allows remote employees to access a secure encrypted tunnel using their mobile, computer and securely connect backc to the organization's network. VPN systems can also securely interconnect branch offices with central office network.
5. Anti-virus or Anti-malware  
    These applications use signature or behavior analysis to detect and block malicious code from running in your device/network.
6. Other Security Device  
    Other security devices include web and email security appliances, decryption devices, client access control servers and security management system

**Firewall**

In networking, firewalls are designed to control and filter which communications are allowed and which are disallowed. Firewalls can come into 2 types, a standalone application on a personal device (Host-based firewall), or a standalone network device that protects and filters communication between numerous computer devices on that network (Network-based Firewall).

As malicious traffics are becoming more and more advanced, new firewalls have been developed.

- Network Layer Firewall: Filters traffic based on source and destination IP address
- Transport Layer Firewall: Filters communication based on source and destination data ports as well as connection states
- Application Firewall: Filters based on application, program or services
- Context Aware Firewall: Filters based on users, device, threat device, application type and role.
- Proxy Server: Filters based on URL, domain names and media types.
- Reverse Proxy Server: Placed Infront of the web server, it hides, protects, offloads and distributes access of the web servers.
- Network Address Transaction (NAT) Firewall: It hides the private addresses of network hosts
- Host-Based Firewall: Filters ports and system service calls on a single computer operating system.

**Port scanning**

Each device on a network is assigned with an identifier called port number. Port number is used on both end of the communication so that data transmission is sent to the right destinations. Port Scanning is the act of probing a device, network or server for open ports.

How Port Scanning is done:

- Zen Map: It is an official Nmap Security Scanner GUI which can allow you to perform a network mapping (Nmap) on a server, computer or network to find open port. It is an open source project. [https://nmap.org/zenmap/](https://nmap.org/zenmap/)

The scan will also report one of the following responses:

1. ‘Open’ or ‘Accepted’ means that the port or service running on the computer can be accessed by other network devices.
2. ‘Closed,’ ‘Denied’ or ‘Not Listening’ means that the port or service is not running on the computer and therefore cannot be exploited.
3. ‘Filtered,’ ‘Dropped’ or ‘Blocked’ means that access to the port or service is blocked by a firewall and therefore it cannot be exploited.  
    To execute a port scan from outside of your network, you will need to run it against your firewall or router’s public IP address.

Enter the query ‘what is my IP address?’ into a search engine such as Google to find out this information.

Go to the [Nmap Online Port Scanner](https://hackertarget.com/nmap-online-port-scanner/), enter your public IP address in the input box and press ‘Quick Nmap Scan.’ If the response is open for ports 21, 22, 25, 80, 443 or 3389 then most likely, port forwarding has been enabled on your router or firewall and you are running servers on your private network.

**Intrusion Detection and Prevention Systems**

Intrusion Detection Systems (IDS) and Intrusion Prevention Systems (IPS) are security measures kept in place to prevent and malicious activities on a network.

An IDS can either be a dedicated network device or one of several tools in a server, firewall or even a host computer operating system, such as windows or linux, that scans data against a database of rules or attack signatures, looking for malicious traffic.  
When a match is detected, the IDS will generate a log and alert a network administrator. This doesn't prevent attacks from happening as they don't perform any action. The job is to detect, log and report.

While scanning, the IDS can slow down the network (known as latency). To prevent network delay, IDS are usually placed offline, separated from the regular network. Data is copied or mirrored by a switch and then forwarded for offline detection.

An IPS can block or deny traffic based on a positive or signature match. Snort is one of the best IPS/IDS tools. The commercial version of Snort is Cisco's Sourcefire. It can perform real time traffic and port analysis, logging content searching and matching as well as detecting probes, attacks and execute port scans. It is also integrated with other third-party tools for reporting, performance and log analysis.

**Real time detection**

Detecting attacks in real time requires actively scanning for attacks using firewalls and IDS/IPS networking devices. Next generation client and server malware detection with connections to online global threat centers must also be used. Many organization lack the ability to perform real-time detection and take days or even months to detect attacks.

Active scanning devices must detect network anamalies using context-based analysis and behavior detection.

DDoS is one of the biggest attacks that requires a real time detection and response. For many organization, regularly occurring DDoS attacks cripple Internet servers and network availability. These attacks are extremely difficult to defend against because the attacks originate from hundreds, even thousands, of zombie hosts, and the attacks appear as legitimate traffic.

**Behavior based Threat Analysis**

It is the form of threat detection where communication between a local user and a local or a remote user is captured and analyzed. Any changes in local pattern is taken as an anomalies and may indicate an attack.

1. Honeypot  
    Honeypot is a behavior based threat analysis tool that lures the attacker based on predicted behavior into a "honeypot", once in it the network administer captures, analyses and logs their behavior to improve the defense of the network.
2. Cisco's cyber threat Defense Solution Architect  
    This is a behavior based security architecture that provides more context, control and overview of the attack. It is done with the help of many advanced security tool. the aim is to know who is carrying out the attack, when the attack took place, what attack they used, how and where it happened and many more.

**Netflow**

Netflow technology is used to gather the flow of communication happening in the internet, including who or what device is on the network, when and how they accessed the network.

Netflow is an important component in behavior-based detection and analysis. Switches, routers and firewall equipped with netflow technology can create network information about data entering, leaving and flowing through the network.

This information is then sent to Netflow collectors who then collect, store, and analyses Netflow data, which can then be used to establish baseline behaviors for over 90 attributes, such as source and destination IP.

**Penetration Testing**

Also known as pen testing is the act of forcing your way into the network to learn about previously unknown vulnerability. A pen tester's main goal is to breach system, people, process and code to find vulnerability that could be exploited. The test results is then used to improve the system's defense so it is more able to withstand future cyber attacks.

Listed below are the 5 step pen testing process:

**Step 1:** Planning  
The pen test gathers as much information as possible about a target system, potential vulnerability or exploit that can be used against it. This involves active and passive reconnaissance and vulnerability research.

**Step 2:** Scanning  
The pen tester carries out active reconnaissance to probe the target network or system to find vulnerability which can be exploited to gain access. Active reconnaissance may include:

- Scanning for open ports to find potential access point into the system
- Vulnerability scanning to find potential weaknesses
- establishing an active connection (enumeration) on the target to identify user account, system account and admin account

**Step 3:** Gaining access  
Pen testers will then try and gain access to the system using various methods such as

- launching an exploit with a payload onto the system
- breaching physical barriers to assets
- social engineering
- exploiting website vulnerabilities
- exploiting software and hardware vulnerabilities or misconfigurations
- breaching access controls security
- cracking weak encrypted Wi-Fi.

**Step 4:** Maintaining access  
The pen tester will then maintain access of the system while trying to be undetected, figuring out what files and folders are vulnerable to exploitation. It done typically with blackdoor, trojan horse, rootkits or other covert channels so they can remain undetected. Once it is done, the pen tester will then proceed to gather data that they think is valuable

**Step 5:** Report and Analysis  
The pen tester will then provide an analysis, providing details guides on how to improve the products and what training to provide to the employee.

**Impact Reduction**

There is no security that keeps data 100% safe, attackers are constantly evolving and finding new ways to breach data due to this some measures have been developed to reduce data loss.

1. Communicate the issue  
    Communicating clearly provides clarity on what to do in the situation. All employees should be told about the plan of action on what to do and all the client should be informed using direct communication or official announcements.
2. Be sincere and accountable  
    Take accountability for where the organization is at fault and be truthful by responding to the breach in an honest and genuine way.
3. Provide the details  
    Be open about what happened and what data was compromised. Organizations are generally responsible for any client cost associated with identity theft services required as a result of security breach.
4. Find the sources  
    Finding the cause or the source of the breach is important. A forensic expert team may need to be hired to perform such actions. and find the details
5. Apply lesson learned  
    Make sure anything you learned from the forensic team is taught to the employees so similar breaches don't occur in the future
6. Check, and check again  
    Make sure there is no backdoor or a way for attackers to get into the system again. Make sure the system is clean, no backdoor is installed and nothing else is compromised
7. Educate  
    Educate, train and make employees, client and partners aware so that similar breaches don't occur in the future

**Risk Management**

Risk Management is the process of continuously assessing the impact of threat in an effort to reduce the impact of threats and vulnerabilities. The cost of control should never exceed the value of the asset you are protecting. You can never eliminate risk completely, what you can do is determine the impact of the threat with cost implementing controls.

- **Frame the risk**  
    Identify the threats that increase risk. Threats may include processes, products, attacks, potential failure or disruption of services, negative perception of an organization's reputation, potential legal liability or loss of intellectual property.
- **Respond to the risk**  
    Develop an action plan to reduce overall organization risk exposure, detailing where risk can be eliminated, mitigated, transferred or accepted.
- Assess the risk  
    Determine the severity that each threat poses. For example, some threats may have the potential to bring an entire organization to a standstill, while other threats may be only minor inconveniences. Risk can be prioritized by assessing the financial impact or scaled impact on an organization's operation.
- Monitor the risk  
    Continuously review any risk reduced through elimination, mitigation or transfer actions. All risk can't be eliminated so you will need to closely monitor any threats that have been accepted.

**Cisco's CSIRT**

Many large organizations have a Computer Security Incident Response Team (CSIRT) to receive, review and respond to computer security incident reports. Cisco CSIRT goes a step further and provides proactive threat assessment, mitigation planning, incident trend analysis and security architecture review in an effort to prevent security incidents from happening.

Cisco’s CSIRT takes a proactive approach, collaborating with the Forum of Incident Response and Security Teams (FIRST), the National Safety Information Exchange (NSIE), the Defense Security Information Exchange (DSIE) and the DNS Operations Analysis and Research Center (DNS-OARC) to ensure we stay up-to-date with new developments.

There are several national and public CSIRT organizations, like the CERT Division of the Software Engineering Institute at Carnegie Mellon University, that are available to help organizations and national CSIRTs to develop, operate and improve their incident management capabilities.

**Security Playbook**

One of the best ways to prepare for a security breach is to prevent it. Organizations should provide guidance on:

- how to identify the cybersecurity risk to systems, assets, data and capabilities
- the implementation of safeguards and personnel training
- a flexible response plan that minimizes the impact and damage in the event of a security breach
- security measures and processes that need to be put in place in the aftermath of a security breach.

All this information should be compiled into a security playbook.

A security playbook is a collection of repeatable queries or report that outline a standard process for incident detection and response. A security playbook should:

- Highlight how to identify and automate responses to common threats such as the detection of malware-infected machines, suspicious network activities or irregular authentication
- describe and clearly define inbound and outbound traffic
- provide summary information including trends, statistics and count
- correlate events across all relevant statistics
- provide usable and quick assess to key statistics and metrics

- Data in motion (data travelling throughout the network)
- Data at rest (data stored in a computer network or device)
